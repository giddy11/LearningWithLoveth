Using clamp() for fluid sizes

Font sizes and spacing scale smoothly with the viewport — readable on phones and comfortable on desktops.

Why fluid type?

Fixed breakpoints can cause awkward jumps. With clamp(min, preferred, max), sizes grow within a safe range. Try resizing this page.

Guidelines

  • Start with mobile‑first sizes.
  • Use ch width for readable paragraphs.
  • Don’t let lines get too long.
